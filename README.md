### What I'm building

**[aws-platform-terraform](https://github.com/BenitesG/aws-platform-terraform)** — a production AWS account as code, sanitized.
A golden image factory on EC2 Image Builder with four stacked lineages (x86 + Graviton), six EC2 instances with no inbound
port reached only through Session Manager, cross-account VPC peering, and a Python + duckdb tool for VPC Flow Log forensics.
CI runs `fmt`, `validate`, tflint and checkov on every push — with no cloud credentials, on purpose.
The decisions *and the mistakes* are documented inside the code: a CRLF conversion that planned to replace the whole image
pipeline with a clean `git status`, a CIDR passed along and never verified, a permissions boundary denying without naming itself.

**[MultiAssetAnalyticsSystem](https://github.com/BenitesG/MultiAssetAnalyticsSystem)** — polyglot microservices in C#/.NET 8 and Python.
API Gateway in Minimal APIs with BCrypt and Polly, distributed Redis cache keyed by a SHA-256 signature of the portfolio state
(which zeroes AI inference cost on repeated queries), five services in Docker Compose with healthchecks against migration race
conditions, and TDD with xUnit and Moq.
